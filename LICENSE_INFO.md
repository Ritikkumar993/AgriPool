## 📞 Questions?

### Can I change the license later?
- Yes, but only for new versions
- Existing versions stay MIT licensed

### Can I use a different license?
- Yes! You can choose:
  - **Apache 2.0** - Similar to MIT, more explicit about patents
  - **GPL** - Requires derivative works to be open-source
  - **BSD** - Similar to MIT
  - **Proprietary** - Closed source

### Do I need to add copyright to every file?
- No, the LICENSE file at the root is enough
- Optional: Add a header to main files

### Can I dual-license?
- Yes! You can offer both MIT and commercial licenses
- Example: "MIT for open-source, paid for commercial"
